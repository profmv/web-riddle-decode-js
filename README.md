# Estação Cifra

Jogo de quatro portões de JavaScript para duplas ou trios. A turma constrói um decodificador no VS Code, reaproveita as funções a cada novo desafio e usa o jogo para conferir as mensagens.

[Abrir o jogo no GitHub Pages](https://profmv.github.io/web-riddle-decode-js/)

## Em sala

1. Abra o jogo e use a seção **Kit para o VS Code** para baixar os três arquivos para uma única pasta.
2. Edite `decodificar(mensagem)` em `decoder.js`. Abra o `index.html` do kit e atualize a aba após salvar o código.
3. Copie a mensagem cifrada do portão para o kit. Rode seu código e cole o texto recuperado no jogo.
4. Troque os papéis após cada acerto. Os portões abertos ficam disponíveis para consulta.

O percurso salva o progresso no navegador. Use **Reiniciar percurso** no fim da página para jogar desde o início.

## Prévia no Windows

Com Python instalado, rode `.\iniciar.bat` no PowerShell e abra [a prévia local](http://127.0.0.1:8000/). Se precisar mudar a porta, rode `.\iniciar.bat 8010` e ajuste a URL.
