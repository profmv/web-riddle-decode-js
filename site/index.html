        Kit para o VS Code

        Usem os mesmos arquivos do primeiro ao último portão.

        index.html style.css decoder.js
        1. Baixem os três arquivos, guardem os nomes e coloquem tudo na mesma pasta.
        2. Abram a pasta no VS Code e editem a função decodificar(mensagem) em decoder.js.
        3. Abram o index.html do kit no navegador. Salvem e atualizem a aba a cada teste.
        Como dividir as tarefas

        Uma pessoa programa e outra lê a regra e revisa a lógica. Se houver uma terceira, ela propõe testes com espaços, pontuação e a passagem do A ao Z. Troquem os papéis a cada portão.
